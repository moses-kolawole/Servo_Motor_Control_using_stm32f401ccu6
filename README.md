# Servo_Motor_Control_using_stm32f401ccu6

## Overview
This project demonstrates how to control a servo motor using Pulse Width Modulation (PWM) generated by the STM32F401CCU6. The PWM signal is configured to operate at 50 Hz, while the pulse width is varied to rotate the servo smoothly between 0° and 180° before returning to its starting position.

## Final Outcome
- Servo motor rotates smoothly from 0° to 180°.
- Servo returns smoothly from 180° back to 0°.
- Continuous back-and-forth motion using PWM.

## Features
- 50 Hz PWM signal generation
- Servo angle control through pulse width variation
- Smooth bidirectional movement
- Timer-based PWM using TIM3
- Register-level (Bare-Metal) STM32 programming

## Hardware Used
- STM32F401CCU6 Black Pill
- ST-Link V2 Programmer
- SG90 Servo Motor (or compatible)
- External 5V Power Supply (recommended)
- Breadboard
- Jumper Wires

## Learning Objectives
- Understand how servo motors are controlled using PWM.
- Learn how pulse width determines servo position.
- Configure TIM3 for 50 Hz PWM generation.
- Generate precise PWM signals using STM32 timers.
- Gain experience interfacing actuators with STM32 microcontrollers.
